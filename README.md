# Nashrino

Nashrino is a Persian-first, RTL social-media publishing and operations dashboard built with Next.js 15, React 19, TypeScript, and Tailwind CSS v4.

## Current stabilization phase

The repository is being restored from the current frontend prototype into a reliable source structure. Work is tracked on the `phase-0-stabilize` branch before changes are merged into `main`.

## Local development

Requirements:

- Node.js 22 or newer
- npm

```bash
npm install
npm run dev
```

The application starts at `http://localhost:3000`.

## Quality commands

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Product direction

Nashrino is an operational command center for multi-platform content publishing, approvals, campaign execution, inbox triage, analytics, and platform health. The interface is Persian RTL and must remain fully responsive across desktop, tablet, and mobile.
